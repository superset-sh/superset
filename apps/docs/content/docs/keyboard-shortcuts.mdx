## Workspace

| Action | Shortcut |
|--------|----------|
| New Workspace | ⌘N |
| Quick Create Workspace | ⌘⇧N |
| Open Project | ⌘⇧O |
| Switch to Workspace 1-9 | ⌘1-9 |
| Previous Workspace | ⌘⌥↑ |
| Next Workspace | ⌘⌥↓ |

| Check Resources | ⌘⇧U |

## Customize

Open Settings → Keyboard Shortcuts to rebind or disable any hotkey. **Reset** next to a shortcut restores its default.
