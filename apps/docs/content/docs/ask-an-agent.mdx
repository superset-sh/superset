---
title: Ask an agent
description: Search and read Superset documentation with an AI agent using MCP or Markdown.
---

Your agent can look up existing answers in the Superset docs before troubleshooting a problem or filing feedback. Documentation access is public and requires no Superset account.

## Start with the documentation index

Give your agent this prompt:

```text
Read https://docs.superset.sh/llms.txt and find the pages relevant to my
question. Fetch those pages as Markdown, explain the answer, and link to
the documentation you used. If the docs do not answer it, say what is missing.
```

Then describe your question or symptom. Include your platform and Superset version when they matter.

| Resource | Use it for |
| --- | --- |
| [Documentation index](https://docs.superset.sh/llms.txt) | Finding pages by title and description |
| [One page as Markdown](https://docs.superset.sh/llms.mdx/troubleshooting) | Reading a relevant page without the site's navigation |
| [Full documentation](https://docs.superset.sh/llms-full.txt) | Searching across the whole corpus when the index is insufficient |

To read any page as Markdown, prefix its path with `/llms.mdx`. For example, `/cli/getting-started` becomes `https://docs.superset.sh/llms.mdx/cli/getting-started`. Start with the index and relevant pages to keep the amount of text your agent needs to read small.

## Search through MCP

If your agent supports remote MCP servers, add a Streamable HTTP server named `superset-docs` with this URL:

```text
https://docs.superset.sh/mcp
```

This server provides read-only documentation tools:

| Tool | Input | Result |
| --- | --- | --- |
| `docs_search` | `{"query":"workspace setup scripts"}` | Up to ten keyword matches with titles, descriptions, paths, and source URLs |
| `docs_read` | `{"path":"/setup-teardown-scripts"}` | The selected page's content as Markdown |

Search with a few relevant product terms, then pass a result's `path` to `docs_read`. Read the page before answering; search results only identify candidate pages. Link to the result's source URL in the answer. If the first query misses, try the feature name or a shorter error phrase. Keep private paths, account details, and logs out of queries.

The documentation server needs no authentication. The [product MCP server](/mcp-server) at `https://api.superset.sh/mcp` is a separate connection for actions on your Superset account, such as creating workspaces and tasks.

## When an answer does not resolve the problem

Check whether the instructions apply to your platform and version, and verify whether a suggested fix works. If you still need help, ask your agent to use the feedback skill and include the relevant documentation and what you tried. You can still send feedback about a documented behavior or workaround.
