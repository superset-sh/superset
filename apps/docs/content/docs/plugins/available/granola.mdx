Search and read your Granola meeting notes and transcripts.

## Skills

| Skill | What it does |
|:------|:-------------|
| `find-in-granola` | Answers "what did we say, decide, or promise" from your meeting notes |
| `follow-up-from-granola` | Finds your commitments in a meeting and does each one, or drafts it |

Skills are named `granola-<skill>`. In Claude Code they appear as `superset:granola-<skill>`.

## MCP Server

Tools come from Granola's own MCP server at `https://mcp.granola.ai/mcp`. Superset proxies each call and adds your credentials. Granola decides which tools the server offers, so see Granola's documentation for the current list.

## Authentication

| Method | Details |
|:-------|:--------|
| OAuth 2.0 | You sign in to Granola in your browser. Superset registers itself with Granola when you connect, so there is no app to set up first. |

Connect from the plugin's page in **Plugins**. Superset keeps the credentials. The agent and your machine never see them.
