# Remote onboarding demo artifacts

Captured live over CDP against a dev desktop plus a second host-service registered through the
local relay, with a real private repo. The API key visible in the add-host guide is blurred and
was revoked after filming.

| File | Shows |
| --- | --- |
| `add-host-flow.gif` | Device picker, "Add another device…", the guide minting a key and writing the one-line paste, the host connecting |
| `remote-onboarding-flow.gif` | The whole path: add a host, pick host and project, clone access fails, fix it, one submit clones and opens the workspace |
| `project-picker-hints.png` | Project list with a host selected: entries that will be cloned are marked |
| `clone-pill-fix.png` | Clone plan pill after a failed access check, with the command that fixes it |
| `clone-pill-verified.png` | Same pill once access is verified |

Background and follow-ups: `apps/desktop/plans/20260817-remote-onboarding-improvements.md`.
