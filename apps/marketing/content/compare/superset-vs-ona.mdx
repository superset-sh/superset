Ona and Superset both run coding agents in parallel, but they put the work in different places. Ona, formerly Gitpod, runs each agent in its own cloud environment, so you assign a task, close your laptop, and get a pull request back. Superset is a desktop app that runs any CLI agent in Git worktrees on your laptop or on hosts you own, and you review the work in the app or on your iPhone. Choose Ona if you want managed cloud environments, VPC deployment, and enterprise governance. Choose Superset if you want agents on your own machines, a full review GUI, and a free tier.

## At a Glance

| Requirement | Superset | Ona |

## What Is Ona?

[Ona](https://ona.com) is the new name of Gitpod, the cloud development environment company. It now calls itself "The Enterprise software factory." Ona runs AI engineering agents in the cloud: you describe a task, an agent works in its own full environment with your tools and permissions, and it returns a pull request. Fleets of agents can run repeatable workflows triggered by pull requests, schedules, or webhooks.

Environments are defined as code with Dev Containers, so each one starts the same way. You can open an environment in VS Code, VS Code in the browser, Cursor, Windsurf, JetBrains IDEs, or any editor that connects over SSH. Enterprise customers can run Ona in their own VPC on AWS or GCP, with network control, SSO, audit trails for human and AI actions, and policy controls. Ona's homepage also says it is "Part of OpenAI," and links to a post announcing that Ona is joining OpenAI.

## Should my agents run in the cloud or on my own machines?

This is the main difference. Ona's cloud environments keep running when your laptop is closed, scale up to large machines, and give each agent a clean, separate environment. That suits long tasks, large teams, and companies that want every agent run inside a governed network.

Superset is local-first. Agents run on your laptop or on a machine you add as a host, such as a desktop at home or a shared server. Your code, credentials, and tools stay on hardware you control, and Superset never proxies model calls. To keep work going while you are away, run agents on a host that stays online and check in from the iPhone app. Superset has cloud workspaces too, but they are in early access for some accounts and not generally available, so plan around your own hosts today. See [running coding agents on a remote machine](/compare/run-coding-agents-on-remote-machine) for setups.

## How isolated is each agent?

Ona gives each agent a full cloud environment, which separates files, processes, and network access. Two agents cannot fight over a port or a local database.

Superset gives each task its own Git worktree and branch. That separates working files, but processes share the host, so dev servers need separate ports and services need a plan. Setup and teardown commands per project help with this. If you need a hard sandbox for untrusted code today, Ona is the stronger fit. See [how to isolate parallel coding agents](/compare/isolate-parallel-coding-agents) for the trade-offs.

## Where do I review the agent's work?

In Ona, an agent's main output is a pull request, and you can open its environment in your editor to look closer. Review then happens in your Git host and IDE.

Superset puts review in the app. The Workspaces page groups every workspace by state, such as Needs attention or Needs review. The Changes pane lets you read the diff, commit, push, and open a pull request. The PR pane shows checks and review threads and can merge. A browser pane with Design Mode lets you preview the app and send an element to the agent. You can watch the agent's terminal while it works and correct it before it finishes.

## Which agents can I use?

Ona's site names its own agent and Codex, and its Core plan lets you connect an existing Codex subscription. Its docs say you can bring configuration from Claude Code or Cursor. For other agents, see their docs.

Superset runs any CLI agent, including Claude Code, Codex, OpenCode, and others, side by side in the same project. You use your own provider accounts.

## Pricing

Ona's Core plan starts at $20 per month and includes 80 to 2,200 Ona Compute Units (OCUs) per month. OCUs pay for environment runtime and agent conversations, and add-on OCUs start at $10 for 40. Core has no per-seat fee for up to 100 members. Enterprise has custom pricing with VPC deployment. We found no free tier. See [Ona pricing](https://ona.com/pricing).

Superset has a Free plan for one user. Pro costs $20 per user per month, or $15 billed yearly, and adds automations, remote hosts, the iPhone app, and GitHub, Linear, and Slack integrations. Enterprise is custom. Compute is your own hardware, so there are no usage credits. See [pricing](/pricing). With both products, check how model usage is billed for the agents you choose.

## Choose Ona if / Choose Superset if

**Choose Ona if:**

- You want agents to run in managed cloud environments while your laptop is off.
- Each agent needs a full, separate environment, not only a separate worktree.
- You need deployment in your own VPC with SSO, audit trails, and policy controls.
- Your team already uses Dev Containers or worked with Gitpod.

**Choose Superset if:**

- You want agents to run on your laptop or on machines you own.
- You want to use any CLI agent, including Claude Code, side by side.
- You want diffs, commits, PRs, checks, and a browser preview in one desktop app.
- You want a free tier and per-seat pricing with no usage credits.

## Verdict

Ona is the better fit for teams that want cloud background agents with strong isolation and enterprise controls, and it has a long history in cloud development environments. Superset is the better fit for developers who want to keep agents on their own hardware, watch and steer them, and review and ship their work in one app. Superset's own cloud workspaces are early access only, so if fully hosted agents are a must today, Ona is the more complete option.

## Frequently Asked Questions

### Is Ona the same as Gitpod?

Yes. Gitpod renamed itself Ona in 2025 as it moved from cloud development environments to software engineering agents.

### Does Superset run agents in the cloud?

Superset runs agents on your laptop or on remote hosts you add. Cloud workspaces are in early access for some accounts and not generally available. Remote access to your own machines is available on Pro today.

### Can Superset agents keep working when my laptop is closed?

Yes, if they run on a host that stays online, such as a desktop or server you add as a remote host. You can check on them from the iPhone app.

### Does Ona support Claude Code?

Ona's site names its own agent and Codex. Its docs say you can bring configuration from Claude Code. Check their docs for current agent support.

### Which is more isolated?

Ona. Each agent gets a full cloud environment. Superset uses a Git worktree per task, which separates files but not processes or ports.
