Omnara started as a web and mobile app for running Claude Code and Codex sessions from your phone, and its iOS app, "Omnara: Claude & Codex Mobile", is still on the App Store. On September 2, 2026, Omnara relaunched omnara.com as an open-source managed agents API, and its current site and docs no longer describe the coding app. Superset is a desktop workspace app that gives each task its own Git worktree and branch, with an iPhone app to check on agents, reply, and review diffs. If you are choosing a phone companion for Claude Code and Codex today, compare the App Store app with Superset, and confirm Omnara's plans for that app before you depend on it.

## What Is Omnara?

Omnara (YC S25) launched as a way to run Claude Code and Codex from anywhere. A small headless daemon on your machine or a VM hosts the agent loop and keeps an outbound WebSocket to Omnara's server, so you open no ports and set up no SSH. The founders rebuilt it on the Claude Agent SDK and use the Codex app server for Codex. With cloud sync on, a session can move to a hosted sandbox when your laptop goes offline, because Omnara commits the code at each turn.

The App Store app is free with no in-app purchases listed. Its listing describes diffs and approvals, live localhost previews of your dev server, a two-way voice coding mode, and splitting a task into parallel sub-agents. Its latest listed version is 2.0.5, which added Apple Watch support.

Since the relaunch, omnara.com, its docs, and its GitHub repository describe a different product: an API to deploy agents on any model and machine, billed by token and machine time. The docs mention Claude Code and Codex only as MCP clients that connect to that API. We could not find a statement about the future of the coding app.

## Which is better for monitoring agents from an iPhone?

Both keep the agent on your computer and let you steer it from the phone. Our guide to [monitoring coding agents from an iPhone](/compare/monitor-coding-agents-from-iphone) compares them with Claude Code Remote Control, Codex in the ChatGPT app, and SSH with tmux.

Omnara's app covers more Apple devices: it lists iPhone, iPad, and Apple Watch, and it has a web client. It also offers a voice mode and localhost previews, which Superset's iPhone app does not.

[Superset for iPhone](/mobile) needs iOS 26 or later and Pro. It lists workspaces across every host you can access, with a marker when an agent is working, waiting for permission, failed, or ready for review. A Live Activity on the Lock Screen and Dynamic Island shows which agents need you, and it updates while the app is closed. You reply in the agent's own terminal session, review diffs file by file, check pull request status, and merge. Push notifications and native iPad support are coming, not shipped. Android is on a [waitlist](/mobile#android).

## Which agents does each support?

Omnara's app is built for Claude Code and Codex. It runs their agent loops through each vendor's SDK or app server.

Superset runs any CLI agent in a terminal, including Claude Code, Codex, OpenCode, Gemini CLI, Amp, and Cursor Agent. The phone shows the same workspaces whichever agent runs in them. See the [agent list](https://docs.superset.sh/agent-integration).

## What happens when my laptop goes offline?

This is where Omnara's design is different. Its opt-in cloud handoff continues a session in a hosted sandbox when your machine drops off, and its listing says uncommitted code carries over.

Superset does not move a session to the cloud. The agent runs on the host you chose, so that host must stay online. For work that should continue overnight, add a machine that stays on as a remote host and run `superset start --daemon` on it. See [running coding agents on a remote machine](/compare/run-coding-agents-on-remote-machine). Superset cloud workspaces are in early access only.

## How do review and parallel work compare?

Superset gives each workspace its own Git worktree and branch, so each agent's diff holds only its own changes. On desktop, the Changes pane commits, pushes, and opens a pull request, and the PR pane shows checks and review threads and can merge. Worktrees separate files but are not a sandbox, and branches can still conflict.

Omnara's app shows diffs and approvals on the phone, and its listing describes parallel sub-agents from one dashboard. How it keeps parallel sessions apart in one repository is not described in its current docs.

## Pricing

At its Launch HN, Omnara listed a free tier of 10 agent sessions per month and $20/month for unlimited sessions, with local sessions using your own Claude or Codex subscription. The App Store listing shows the app as free with no in-app purchases. The current omnara.com pricing page covers the managed agents API, not the coding app, so check current terms with Omnara.

Superset is free for one user. Pro is $20 per user/month, or $15 billed yearly, and covers the iPhone app, remote hosts, automations, and GitHub, Linear, and Slack integrations. Enterprise is custom. See [pricing](/pricing). Superset never proxies model calls.

## Choose Omnara if / Choose Superset if

**Choose Omnara if:**

- You only run Claude Code and Codex and want them on iPhone, iPad, or Apple Watch
- You want sessions to continue in a cloud sandbox when your laptop sleeps
- Voice mode or localhost previews on the phone matter to you
- You are comfortable with a product whose company now focuses on a different offering

**Choose Superset if:**

- You run several CLI agents, not only Claude Code and Codex
- You want each task on its own worktree and branch, created for you
- You want to review, commit, open pull requests, and merge on desktop, then check in from your phone
- Your team shares hosts with access per member
- You want a product whose main focus is coding agent workspaces

## Verdict

Omnara's mobile app has features Superset's iPhone app lacks: iPad and Apple Watch, voice, localhost previews, and cloud handoff. The relaunch of omnara.com as a managed agents API is the main risk, because the current site does not describe the coding app. Superset is the steadier choice if you want one desktop workspace for many agents with an iPhone companion, and you can accept that push notifications and iPad are still coming.

## Frequently Asked Questions

### Is the Omnara mobile app still available?

Yes. "Omnara: Claude & Codex Mobile" is on the App Store at the time of writing. Omnara's current website and docs describe its managed agents API instead, so confirm the app's status with Omnara.

### Is Omnara open source?

The current Omnara platform, the managed agents API, is Apache-2.0 on GitHub. The founders' launch post for the coding app did not state a license. Superset is source-available under Elastic License 2.0.

### Does Superset send push notifications to my iPhone?

Not yet. Today a Live Activity on the Lock Screen and Dynamic Island shows which agents need you, are working, or are ready for review. Push notifications are coming.

### Does Superset have an iPad app?

Not a native one yet. Native iPad support is coming. The iPhone app is on the App Store and needs iOS 26 or later.

### Do I still pay Anthropic or OpenAI?

Yes, with both. Claude Code and Codex usage is billed by its provider. Superset does not proxy model calls.
