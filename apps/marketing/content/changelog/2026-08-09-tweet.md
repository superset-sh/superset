What we shipped this week @superset_sh 🛳️

1. Resume interrupted agent sessions ⏪
Killing a terminal used to kill the conversation. Laptop reboot, crashed process, whatever, the agent's context was just gone. Now the pane shows an interrupted banner and one click relaunches the agent with its own resume command, claude --resume, codex resume, and so on, right in the same pane. Even panes migrated from the original interface resume, so upgrading to 2.0 doesn't strand your in-flight sessions.

2. A dedicated Pull requests view 🔀
Tasks and PRs each get their own home in the sidebar, and the PR view now filters across several repos at once, by author and review state, with CI check summaries on every row. Community contributed. Open it from Pull requests in the sidebar.

3. Per-project controls 🎨
Icon and color per project, naming instructions that steer AI-generated branch names ("prefix branches with fix/ or feat/"), and sparse checkout so monorepo worktrees only materialize the folders you need. All in Settings → Projects.

4. A CLI that shows you around ⌨️
Run superset with no arguments and you get an interactive command browser: arrow through the commands, read the flags, and guided forms assemble the full command before running it. There's also a built-in Superset CLI preset in the workspace preset bar.

Also this week: superset:* skills auto-provision to Claude Code, Codex, Kimi, Vibe, and Grok (including superset:feedback to reach us directly), Claude Opus 5 and GPT-5.6 Terra/Luna in the model pickers, retry buttons for failed automations, and the public roadmap is back at superset.sh/roadmap.

This changelog draft was created by an automation.

Plus a bunch of bug fixes. Thanks to everyone in the v2 open beta for the reports, please keep them coming!
