## Safer File Editing <PRBadge url="https://github.com/superset-sh/superset/pull/7711" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7693" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7692" />

Edit files next to your agents without losing work when a script or agent changes the same file.

- A banner tells you when the file changed on disk, with **Compare** to see both versions side by side
- Save conflicts offer **Keep editing**, **Reload from disk**, or **Overwrite file**, instead of silently replacing the newer version
- Turn on auto save after a delay, on focus change, or on window change in **Settings → General**, contributed by [@theblondealex](https://github.com/theblondealex)
- Double-click to rename and drag to move files in the file tree, contributed by [@theblondealex](https://github.com/theblondealex)

![Editor banner saying the file changed on disk, with a Compare link](/changelog/2026-09-28-file-changed-banner.png)

Docs: [Editor](https://docs.superset.sh/docs/editor).

## Workspaces Start Instantly <PRBadge url="https://github.com/superset-sh/superset/pull/7518" />

New workspaces and sessions open in about a second instead of waiting 5 to 20 seconds for an agent to name them. Your agent starts right away, and a name arrives a few seconds later.

- Linked GitHub issues and pull requests in your prompt help pick the name
- Questions and short prompts get a name too, refined after the agent's first reply
- Renaming a workspace yourself always wins

Docs: [Workspaces](https://docs.superset.sh/docs/workspaces).

## GPT-6 and Claude Opus 5.5 <PRBadge url="https://github.com/superset-sh/superset/pull/7741" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7783" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7894" />

Pick GPT-6 Astra, Sol, or Luna and Claude Opus 5.5 from the model picker when you start an agent, contributed by [@haydenfd](https://github.com/haydenfd).

- GPT-6 works in Codex, OpenCode, and OMP, with Ultra effort on GPT-6 Astra in Codex
- Usage tracks costs for the new models
- Retired models no longer show up in the picker

Superset Mobile is live. Check on your agents, review diffs, and read Pages from your phone. Get it from the [App Store](https://apps.apple.com/app/id6788926383) or read the [launch post](https://superset.sh/blog/superset-mobile).

![Superset Mobile running a coding agent on an iPhone](/images/blog/superset-mobile/hero.png)

- Setup in **Settings → Mobile** is now two steps with Remote Access turned on in place <PRBadge url="https://github.com/superset-sh/superset/pull/7697" />
- The app tells a computer that never connected apart from one that went offline, and says what to do next <PRBadge url="https://github.com/superset-sh/superset/pull/7661" />
- The ⋯ menu on a workspace can rename, pin, share, or delete it, and workspace details list its pull requests <PRBadge url="https://github.com/superset-sh/superset/pull/7816" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7782" />

## Improvements

- **Clone from your GitHub repositories** - search the repositories your GitHub login can reach when you add a project, contributed by [@theblondealex](https://github.com/theblondealex) <PRBadge url="https://github.com/superset-sh/superset/pull/7694" />
- **Sign in without leaving Settings** - sign in to Claude Code and Codex accounts from a terminal inside **Settings → Usage** <PRBadge url="https://github.com/superset-sh/superset/pull/7740" />
- **Page links unfurl in Slack** - posted page links show a title and preview to people who can open them <PRBadge url="https://github.com/superset-sh/superset/pull/7817" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7821" />

- **Rejoin the leaderboard with your full history** - choose to publish everything since launch or the last 30 days <PRBadge url="https://github.com/superset-sh/superset/pull/7651" />
- **Google Calendar triggers removed** - nobody used them; Gmail triggers stay <PRBadge url="https://github.com/superset-sh/superset/pull/7796" />
