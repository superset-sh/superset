What we shipped this week @superset_sh 🛳️

1. A Workspaces page built for triage 🗂️
Once you're running a fleet of agents, "what exists" stops being the question. "What needs me" is. So we rebuilt the Workspaces page around status: Needs attention, Working, Needs review, Idle, Merged, with live agent state, diff size, and CI progress on every row. You can sweep 50 workspaces without opening one.

2. Edit markdown in the rendered preview ✍️
Open any markdown file, hit Preview, and just type. Checkboxes click, ⌘S saves. Saves only rewrite the blocks you touched, so your bullet styles and hand-wrapped lines survive and diffs stay clean.

3. Desktop settings from the CLI ⚙️
Run `superset settings set terminalFontSize 16` and the running app updates instantly. 35 settings plus themes, no cloud login. Handy for dotfiles, and for agents that configure your app from a Superset terminal.

4. Sidebar groups go anywhere 🧲
Groups were stuck at the bottom of each project. Now you can drag them above, between, or below ungrouped workspaces and the order sticks.

Also this week: a host unreachable screen with one-click retry, ⇧-click a folder link in the terminal to open it in Finder, a faster sidebar on big repos, Sign in with Apple on iOS, and account deletion with a 30-day grace period.

This changelog draft was created by an automation.

Plus a bunch of bug fixes. Thanks to everyone in the v2 open beta for the reports, please keep them coming!
