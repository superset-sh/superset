## Commit, Push, and Create a PR From the Changes Pane <PRBadge url="https://github.com/superset-sh/superset/pull/7102" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7139" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7166" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7196" />

The Changes pane is now one surface for the whole branch: the diff, the changed-file list, and every step to a pull request. A pill in the top bar shows the diff stats, and the control next to it walks the branch from Commit to Push to Create PR, then becomes the PR badge once the pull request exists.

- Commit opens a message popover with a generated fallback, and Create PR prefills the title from your latest commit and pushes an unpublished branch for you
- Reply to PR review threads inline in the diff, without leaving for GitHub
- Search the changed-file list by path, and renames match their old path too

Open it with ⌘⇧L or the diff pill in the top bar.

## Image, Video, and PDF Diffs <PRBadge url="https://github.com/superset-sh/superset/pull/7035" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7182" />

Binary files in the Changes pane render with the same viewers the file pane uses. A modified image shows Before and After side by side, at the version the diff compares (staged, against base, or a commit), not only the working tree. Videos and PDFs wait behind a Preview button so a large changeset stays light. [@theblondealex](https://github.com/theblondealex) contributed the image previews.

## Workspaces Page Rebuilt Around Devices <PRBadge url="https://github.com/superset-sh/superset/pull/6901" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7150" />

The page title is now the device you are looking at, with your other hosts a click away, and every row shows which machine it lives on, dimmed when that device is offline.

- Filter by project and by who created the workspace, next to the search box
- Board cards drop the repeated chrome: a muted project line, a state glyph beside the title, and a footer of PR, churn, and activity age
- Search and filters respond instantly, even with hundreds of workspaces
- Main checkouts with a finished agent show in Needs review, like every other surface <PRBadge url="https://github.com/superset-sh/superset/pull/7142" />

## New Models and Reasoning Levels <PRBadge url="https://github.com/superset-sh/superset/pull/7099" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7137" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7045" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7178" /> <PRBadge url="https://github.com/superset-sh/superset/pull/6805" />

Claude Fable 5.1 and GPT-6 Astra are in the model pickers and the usage pricing table. Codex offers its max and ultra reasoning levels on the models that accept them, and Cursor Agent gets a reasoning effort picker of its own. You can also pick a model per launch from the CLI, the SDK, and MCP, contributed by [@Shravankb301](https://github.com/Shravankb301):

```bash
superset agents create --workspace W --agent claude --model claude-fable-5-1
superset ws create --agent codex --model gpt-6-astra
```

- **Leaderboard rank card** - **Settings → Usage** shows your rank, tier, and the token gap to the row above you; opt in with Reveal my rank <PRBadge url="https://github.com/superset-sh/superset/pull/7118" />

- **⌘= and ⌘- follow focus** - a terminal steps its font size, a browser pane steps its zoom, anything else zooms the app; ⌘0 resets <PRBadge url="https://github.com/superset-sh/superset/pull/7174" />
- **Open in** - right-click a link, path, or folder in a terminal and pick where it opens, with the same destinations as **Settings → Links** <PRBadge url="https://github.com/superset-sh/superset/pull/7179" />
- **Terminal scripts from the CLI** - `superset scripts list`, `edit`, and `delete`, plus `add --upsert` to replace a same-named script instead of adding a duplicate <PRBadge url="https://github.com/superset-sh/superset/pull/7215" />
- **Automations** - new Review requested and Assigned pull request triggers, with a people chip for whoever landed on the PR <PRBadge url="https://github.com/superset-sh/superset/pull/7163" />
- **Darker theme** - a near-black theme with Superset's ember accent in the marketplace, contributed by [@0x962](https://github.com/0x962) <PRBadge url="https://github.com/superset-sh/superset/pull/6772" />
- **Remote worktrees follow you** - a worktree you created on another machine gets a sidebar row here as soon as its host is online <PRBadge url="https://github.com/superset-sh/superset/pull/7120" />
- **Pages up to 16 MB** - page documents upload straight to storage, so a page with a dozen screenshots no longer hits the old 3 MB limit <PRBadge url="https://github.com/superset-sh/superset/pull/7159" />
- **Downloads page** - [superset.sh/download](https://superset.sh/download) lists every release with per-OS assets, and Linux auto-downloads like macOS <PRBadge url="https://github.com/superset-sh/superset/pull/7047" />
- **iOS** - session tabs sit at the bottom by your thumb, the PR link moves beside the quick keys, and Copy ID confirms with a notice <PRBadge url="https://github.com/superset-sh/superset/pull/7024" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7116" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7117" />
