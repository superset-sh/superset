What we shipped the last three weeks @superset_sh 🛳️

1. Pin and bulk-manage workspaces 📌
Running lots of agents leaves you with a wall of workspaces, and cleaning them up one at a time is a chore. The sidebar now works like a file manager. Right-click a workspace to pin it above your projects, ⌘-click or ⇧-click to grab a batch, then move, group, or delete them all at once. Bulk delete previews every workspace and flags dirty or unpushed work before anything is removed.

2. Turn your agent into an orchestrator 🕹️
The bet behind Superset is many agents working in parallel, so we made the coordinator an agent too. The new superset-orchestration skill lets the agent you're already talking to, Claude Code or Codex, spin up an isolated workspace per worker, launch an agent in each, follow up over their terminals, and collect the results. Workers can be any mix of agents Superset runs. Install with npx skills add superset-sh/skills.

3. Grok and Kimi Code join the agent lineup 🤖
We want Superset to run every coding agent, not just the big two. xAI's Grok Build and Moonshot's Kimi Code are now first-class agents: their own icons and launch presets, live status in the sidebar, and Grok permission prompts as native notifications. Add them in Settings → Agents.

4. Superset 2.0 starts rolling out 🚀
We've been shipping two apps in one: the original interface and the new 2.0 experience behind an opt-in. We're consolidating on 2.0 so every fix lands in one place, rolling out gradually over the coming weeks. If you're still on the original interface, nothing to do: when it's your turn the upgrade happens automatically. Projects, workspaces, settings, and presets all come along, and your next launch lands in your last active workspace.

Also in there: a denser redesigned sidebar with one-click port and agent cleanup, running terminals come back when you open a workspace, failed agent turns show a red status instead of "working" forever, ⌘F search in the Changes pane, editor and terminal typography controls, prompt history on the new-workspace screen, diff review in the iOS app, the CLI on Intel Macs, and per-launch reasoning effort with --effort.

This changelog draft was created by an automation.

Plus a bunch of bug fixes. Thanks to everyone in the v2 open beta for the reports, please keep them coming!
