## Pages Beside Your Code <PRBadge url="https://github.com/superset-sh/superset/pull/7658" />

Open this workspace's pages and your pinned pages without leaving your code, or ask an agent to make one from **Pages → New page**, beside the Run button.

- Pages appear newest first, with a New badge when an agent publishes one
- New page lets you describe what you need and choose an agent

![New page composer with a request and an agent picker](/changelog/2026-09-20-new-page.png)

## Share Pages With Anyone <PRBadge url="https://github.com/superset-sh/superset/pull/7570" />

Share a report or design with someone outside your team without asking them to sign in: open a page and choose **Share → Anyone with the link**.

- Visitors can read the shared version; comments and the rest of the version history stay private to authorized readers
- Shared links show a preview of the page, and the title menu lets you preview older versions without changing the shared version

## Faster Sessions on iOS <PRBadge url="https://github.com/superset-sh/superset/pull/7552" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7604" />

Switch between your four most recent terminal sessions in a workspace without reconnecting, or start an agent without a repository from **Composer → Project picker → No project**.

## Clearer Workspace Names <PRBadge url="https://github.com/superset-sh/superset/pull/7575" /> <PRBadge url="https://github.com/superset-sh/superset/pull/7650" />

Tell pinned workspaces apart by their project name, and find new worktrees in folders named after the project.

- Pinned rows show the project before the workspace name, contributed by [@pdolega](https://github.com/pdolega)
- Drag a row in a sorted or filtered sidebar to see how to switch to manual ordering

![Pinned workspace rows show the project name before the workspace name](/changelog/2026-09-20-pinned-workspaces.png)

## Improvements

- **Find a teammate's pages** - filter by author beside the search box on the Pages screen <PRBadge url="https://github.com/superset-sh/superset/pull/7547" />
- **New pages open when ready** - a first publish opens the page using **Settings → Links → Pages**; publishing another version leaves your focus alone <PRBadge url="https://github.com/superset-sh/superset/pull/7472" />
- **Publish without a workspace** - publish a standalone HTML file from the CLI, then keep the returned page ID to update it <PRBadge url="https://github.com/superset-sh/superset/pull/7573" />

```bash
superset pages publish report.html --title "Weekly report"
superset pages publish report.html --page <page-id>
```

- **Pro setup checklist** - set up remote access and automations from the sidebar checklist; reopen it from Help after dismissing it <PRBadge url="https://github.com/superset-sh/superset/pull/7494" />
