Why Superset

One window for your whole agent fleet.

Stop juggling terminal tabs. Superset gives every agent its own workspace, and gives you one place to steer them all.

01 / Parallel execution

Run five agents like you'd run one.

Kick off multiple tasks at once. Each agent works in its own git worktree, so nothing collides — you review and merge when they're done.

fix-auth-flow · clauderunning
landing-revamp · clauderunning
db-migration · codexreview
refactor-hooks · geminireview
update-deps · claudequeued
// bring any agent
Claude Code Codex Gemini CLI Cursor OpenCode Amp Aider + any CLI
$ superset run --agent claude
✓ agent attached to workspace
02 / Universal compatibility

Works with every agent you already use.

Claude Code, Codex, Gemini, Cursor — or any CLI. Superset is the surface, you pick the brains. No lock-in, no wrappers.

03 / Isolation

Every task gets a clean room.

Isolated git worktrees per workspace mean agents can't step on each other — or on you. Experiments stay experiments until you merge.

~/project main
│
├─ fix-auth-flow worktree · claude
├─ landing-revamp worktree · claude
└─ db-migration worktree · codex
✓ zero conflicts on main

FAQ

Questions,
answered.

Is my code sent to the cloud?

No. Superset runs entirely on your machine. Agents work against your local checkout in isolated worktrees; nothing is uploaded.

Which agents does it support?

Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Amp, Aider — and any CLI-based agent you point it at.

Do I need an account?

No account required to download and run. Your existing agent subscriptions and API keys just work.

Is it free?

Superset is free for individuals. Team and enterprise plans are on the pricing page.

Windows or Linux?

macOS today. Join the Discord to hear first when other platforms land.
