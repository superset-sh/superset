TL;DR

  • We're already lean. 2 steps, 1 required decision, 0 questions — matches the field's best.
  • Two things we do better than anyone: the live-detecting dependency checklist and the embedded gh auth terminal.
  • Biggest gap: sign-in is dead air. Every winner demos the product during auth; our OAuth round-trip shows a logo and two buttons.
  • The aha is never shown. No agent runs during onboarding; Claude and Linear both perform their value in-flow.
  • Smaller gaps: no trust copy on the GitHub ask, skipped steps never resurface (one-way gate), no completion beat.

Superset — our current flow

Mapped from code. Splash → browser OAuth → auto-created org → two-step wizard → composer.

1

Sign-in

Logo + GitHub/Google buttons + "Last used" badge. Browser OAuth round-trip; the app shows nothing while it happens.

2

Org creation (invisible)

Personal org auto-provisioned server-side; the Create Organization screen is a fallback only.

3

1/2 — "Setup Superset"

Live-detecting checklist (4s poll): GitHub CLI, Claude Code, Codex. Embedded PTY runs gh auth login, auto-copies the code, auto-opens the browser. All skippable.

4

2/2 — "Create or add a project"

Four cards: new / open folder / clone / template. Not skippable — the flow's single required decision, and its completion event.

5

Completion → composer

onboarded_at set (one-way, no re-entry). Lands on "What should we build next?" with agent auto-selected + 3 sample prompts. No tour, no recap, no completion beat.

Best-in-class

  • Live-detecting checklist — statuses flip to Connected even from an external terminal.
  • Embedded gh terminal — code scraped, copied, browser opened automatically.
  • Zero questions, two dots — same call as Cursor, Claude, Linear, Railway.
  • Actionable clone errors — auth failures render an inline fix button, not a toast.

Gaps

  • Sign-in is dead air during our slowest moment (the OAuth round-trip).
  • Aha never shown — no agent runs in-flow; sample prompts are passive chips, after.
  • No trust copy on the GitHub CLI ask.
  • One-way gate — skipped agent connections never resurface.
  • No completion beat — jump-cut into the app.

Recommendations

Ranked by leverage. The first three touch every new user.

1. Animate the OAuth wait with a product simulation

Agents fanning out across worktrees, PRs landing — while the user authenticates.

Claude 01–03 · Railway 02–05 · Lovable 03–06

2. Guided "see it work" first task at completion

Make "Explain how this repository works" the celebrated one-button default, not one of three quiet chips.

Claude 05–06 · Linear 12, 18

3. Trust copy on the GitHub CLI step

State what we never do (e.g. "everything runs locally"). Cheap copy, real conversion.

Linear 13

4. Resurface skipped setup after onboarding

A dashboard "finish setup" affordance for skipped agent connections.

Cursor 13 · Linear 17

5. Add a completion beat

One "you're good to go" moment naming what happened + one shortcut.

Linear 17 · Railway 11

Keep

Live checklist, embedded gh terminal, zero questions, two steps. Don't lengthen the wizard.

Avoid

Lovable's 4-question quiz; Cursor's pre-product paywall.
