Moving a file onto a path that exists now returns a 409 the desktop shows inline. Before, the host threw and the client showed a generic error.

src/move.ts is the whole behaviour change. The rest is the error type and its test.

What changed and why

The move handler checked for an existing target and threw a plain Error, which the router turned into a 500. It now returns a typed conflict, so the client can tell "taken" apart from "broken".
